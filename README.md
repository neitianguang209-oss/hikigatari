# ひきがたり

好きな曲のコード譜を、広告なしで見ながら弾き語りするための自分専用アプリ（PWA）。

- 曲名・アーティスト名で **U-FRET / ChordWiki / 歌ネット** をまとめて検索し、開いた曲だけを1曲ずつ取り込んで表示する
- **ギター**: 原曲の響きのまま、いちばん押さえやすいカポ位置を自動で選ぶ。押さえ方の図を歌詞の上に出す。
  - **通常**: 教本どおりの押さえ方（F・B・Bm などはバレーコードのまま）
  - **かんたん**: 押さえにくいコードだけを省略形や響きの近いコード（F→FM7、B→B7、Bm→Bm7 など）に置き換え、前後のコードへの持ちかえが少ない形を曲全体で選ぶ（`planVoicings`）。変えたところは「弾き方とカポ」に一覧で出る
  - 曲画面の上の段(キーの横)の「教本/簡単」ボタンで、その場で切り替えられる
  - **転調**: 曲の途中の転調を見つけて(譜面に {key:} があればそれを使う)、転調のところに「カポ 2 → 4 に付けかえ」の印を出し、転調後も同じ押さえ方で弾けるコード名にする(`src/music/modulation.js`)。「付けかえない」も選べる
- **ピアノ**: 原曲キーのまま表示し、コードをタップすると鍵盤図（右手の和音・左手のベース音）が出る
- **耳コピ**(まだどのサイトにも譜面が無い新曲向け): 曲の音からコード進行を聴き取って下書きを作る(`src/music/earcopy.js`、計算は端末の中だけ・無料)。打楽器を弱めた12音の強さ＋低音で、拍ごとにコードを照合し、キーを推定してビタビ法でなめらかにする。サイトに譜面が出たらホームで知らせる(`src/lib/watch.js`)
  - **1曲まるごと**: マイク(別の端末やスピーカーで流す)・パソコンで鳴っている音(Chrome/Edge の画面共有の「システム オーディオ」)・音のファイルから。曲が鳴り始めた時刻を見つけ、曲の長さ(Apple Music)が過ぎたら自動で止まる。手早く試すなら試聴30秒(曲の一部だけ・歌詞なし)
  - **歌詞に当てはめる**(`src/music/lyricsfit.js`): 歌詞は LRCLIB(時刻つき歌詞の公開データベース)→ 無ければ歌ネット(時刻なし)から探す(`src/lib/lyrics.js`)。時刻つきなら、歌詞の各行の時刻と聴き取った小節を照らして `|[C]歌詞の[G]途中` の形にし、前奏・間奏・後奏はコードだけの行に。小節線を入れるので自動スクロールも実際の曲と同じ速さで進む。歌い出しでタップすると歌詞の位置がぴったり合い、あとから「早く/遅く」でも直せる。時刻なしの歌詞は、聴きながら各行の歌い出しをタップして合わせる
  - **ふりがな**: UtaTen の歌詞(漢字にふりがな)から「その文字を何拍で歌うか」を数え、行の中のコードの位置の見積もりに使う(寿命=じゅみょう=3拍)
  - **耳で合わせる**: 行をタップすると、その行だけを1・0.75・0.5倍(音の高さはそのまま)で何度でも聴ける。コードは聴き取った時刻に光り、光った瞬間に歌っている文字をタップすると、そこに決まる(`place`)。小節の数は変わらないので自動スクロールはずれない
  - **歌詞を指定**: 歌詞サイトのリンク(歌ネット・UtaTen・J-Lyric・歌詞GET・プチリリ など、Edge Function の `lyrics_url`)か、歌詞そのものを貼り付け
  - 当てはめた歌詞はバックアップ(`app_backups`)には入れない(コードと小節線だけ残す)
- **キー変更**（声に合わせる）、**BPMどおりの自動スクロール**（カウントイン・クリック音・タップテンポ・フットペダル対応）
  - 小節線の無い譜面は、行ごとの長さを「コードの数と歌詞の音数」から見積もる（ChordWiki の小節線つき譜面 10曲・333行で当てはめた式。`src/ui/autoscroll.js` の `estimateBars`）
  - 拍の時計は音の時計(オーディオの時刻)1本。クリックは0.15秒先まで正確な時刻に予約し、コードの目印・今の行・スクロールも同じ時計から出す(画面の書きかえが遅れてもずれない)。再生は行の頭(小節の頭)から始める
  - 曲の長さ（Apple Music の再生時間）が分かる曲は、譜面がちょうど曲の長さで終わるよう進む速さを補正する。ただしクリック音オンの間は、クリックとコードの切り替わりをそろえるため BPM どおり
- 並びは「コード名 → 押さえ方の図 → 歌詞」。コード名と押さえる点は単色(ライトは黒・ダークは白系)。押さえ方の図は U-FRET のように簡素に(1pxの格子・まっすぐなナット・塗りの丸・細いセーハ)、コード名はふつうのサンセリフ
- **自分の歌に合わせる**: アカペラで撮った動画や録音を曲に読み込み(この端末の IndexedDB `media` に保存・同期はしない)、再生しながら譜面を流す。再生中に歌っている行をタップすると「この行はこの時刻」の目印になり、目印のあいだは拍どおりにつないで録音にぴったり合わせる(`beatAtTime` / `timeAtBeat`)。動画は小窓(大きく・隠す)、ゆっくり再生(音程そのまま)、区間リピートも録音で使える
- 1行は折り返さずに1行で見せる（はみ出す行だけ少し縮める。コードだけの長い行は段の数をそろえて折る）
- 検索は曲名・アーティスト名をまとめて入れても、ひらがな・カタカナでもOK。同じ曲名の曲は歌ネットの人気順で並ぶ
- **アーティストから探す**: アーティスト名で検索すると、いちばん上にアーティストの候補が出る(歌ネットのアーティスト検索。かな入力も変換して探す)。押すとその人の曲一覧(歌ネットの人気順・新しい順・曲名順、U-FRET にだけある曲も)。曲を押すと、いつもの検索と同じく U-FRET・ChordWiki・歌ネットの譜面をまとめて開く(Edge Function の `artist`)
- **お気に入り**・最近ひらいた曲・曲ごとの設定（カポ/キー/テンポ/楽器）を、iPhone・iPad・PCで同期
- **Apple Music** で聴いている曲を、iPhoneの「ショートカット」からワンタップで開ける
- 曲の画面の上のバーの **「原曲」** ボタンで、Apple Music のその曲へ(iPhone・iPad は `music://` で Music アプリを直接開く。自動スクロール中なら止めてから)。曲のページ(`appleUrl`)は iTunes の曲データから一度だけ調べて覚える
- **練習の道具**: 区間リピート（行をタップ、または「サビ」などの見出しをタップで段落まるごと）、拍の点滅、コードごとに「いつもこの押さえ方」を覚える、**チューナー**（マイクで音の高さを測る・弦ごとの見本の音）、Apple Music で原曲を聴く
- 最近の検索語、お気に入りの絞り込み、消した曲・外したお気に入りの「元に戻す」、印刷・PDF（操作ボタンを消して譜面だけ）
- 自分で入力・貼り付けした譜面も使える（`[C]歌詞` 形式でも、コード行＋歌詞行の形式でもOK）
- オフラインでも保存済みの曲は開ける

公開先: https://neitianguang209-oss.github.io/hikigatari/

## iPhone・iPadでの使い方

1. 公開URLを **Safari** で開く → 共有ボタン → **ホーム画面に追加**
2. 最初の端末で「はじめる」を押す（この端末が自分専用の鍵になる）
3. ほかの端末は、使っている端末の **設定 → 端末と同期 →「つなぐための6桁の数字」** に出ている数字でつなぐ（数字はそこでいつでも確認・変更できる。5回続けてまちがえると15分つなげなくなる）
4. Apple Music との連携はアプリ内の **設定 → Apple Music** の手順どおり（ショートカットは Safari で開くので、Safari でも一度つないでおく）

PC・iPad のキーボードやフットペダル: スペース＝自動スクロールの開始/停止、↓ / PageDown＝次の行（止まっているときは画面送り）、↑ / PageUp＝前の行、→ ←＝BPM を2ずつ上げ下げ。

## 構成

| 場所 | 中身 |
|---|---|
| `index.html` / `styles.css` | React 18 + htm（CDN・ビルドなし） |
| `src/music/` | コード解析・移調・キー判定（chord.js）、譜面の解析と貼り付け変換（sheet.js）、ギターの押さえ方探索・難しさ・カポ最適化・かんたんモード（guitar.js）、ピアノのボイシング（piano.js） |
| `src/ui/` | 画面（home / song / editor / settings / welcome / apple）、自動スクロール（autoscroll.js）、チューナー（tuner.js、YIN法で音の高さを測る） |
| `src/lib/store.js` | 端末内の保存（IndexedDB）と同期。クラウドが空でも端末のデータは消さない |
| `supabase/functions/hikigatari/index.ts` | Edge Function。サイト検索・譜面取り込み・端末の鍵・同期 |
| `sw.js` | オフライン用。**更新して公開するたびに `CACHE_NAME` の番号を上げる** |
| `icons/icon.svg` | アイコンの元絵(夜の丘で、月を背にギターを弾き語りする人)。PNG は `powershell -ExecutionPolicy Bypass -File icons/render-icons.ps1` で作る(Edge で描いて縮小) |

### Supabase（プロジェクト `gzayrjlhruhvklsidraw` に相乗り）

- テーブル: `hikigatari_songs`（曲とお気に入り・設定）、`hikigatari_devices`（端末の鍵のハッシュ）、`hikigatari_pin`（つなぐための6桁の数字・まちがえた回数・ロック期限。1行だけ）、`hikigatari_pair_codes`（旧方式の使い捨てコード）、`hikigatari_sheet_cache`（取り込みキャッシュ）
- どれも RLS 有効・ポリシーなし＝公開キーでは読めない。Edge Function（service role）だけが読み書きする
- 変更があると `app_backups`（app=`hikigatari`）へ控えを送る。取り込んだ歌詞は控えに入れない（自分で入力した譜面だけ入れる）
- Edge Function の更新: Supabase の MCP / ダッシュボードから `hikigatari` を再デプロイ（`verify_jwt: false`、認証は関数内の端末キーで行う）

### 端末をすべて失くしたとき

設定 → バックアップ用キー を控えていれば、「すでに別の端末で使っている → バックアップ用キーで復元する」で戻せる。
キーも無いときは、SQLで `delete from hikigatari_devices;` を実行すると、次に開いた端末で「はじめる」からやり直せる（曲のデータは残る）。

## ローカルで動かす

```
powershell -ExecutionPolicy Bypass -File serve.ps1
```

http://localhost:5507/ を開く（localhost では Service Worker は登録しない）。

## 注意

譜面・歌詞の権利は各サイトと権利者にあります。このアプリは自分が見るためだけに1曲ずつ取り込む作りです。譜面を人に配ったり公開したりしないでください。
